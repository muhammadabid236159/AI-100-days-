# 🤝 Contributing to 100 Days of AI

Thank you for your interest in contributing! This document provides guidelines for contributing.

## How to Contribute

### 1. Report Issues
- **Bug Report:** Describe the bug clearly with steps to reproduce
- **Suggestion:** Share your ideas for improvements
- **Question:** Ask if something is unclear

### 2. Submit Code

#### Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/AI-100-days-.git
cd AI-100-days-
```

#### Create Branch
```bash
git checkout -b feature/your-feature-name
```

#### Make Changes
- Follow PEP 8 style guide
- Add descriptive comments
- Test your code

#### Commit
```bash
git commit -m "Add feature description"
```

#### Push & PR
```bash
git push origin feature/your-feature-name
```

### 3. Improve Documentation
- Fix typos
- Clarify explanations
- Add examples
- Update progress

## Guidelines

### Code Style
- Follow PEP 8
- Use meaningful variable names
- Add docstrings to functions
- Keep functions small and focused

### Notebook Guidelines
- Add markdown descriptions
- Include clear section headers
- Add output for key examples
- Clean up output before committing

### Commit Messages
- Be descriptive
- Use present tense
- Reference issues if applicable

## Pull Request Process

1. Update README if needed
2. Add relevant tests
3. Update PROGRESS.md
4. Ensure code works
5. Submit PR with description

## Recognition

All contributors will be:
- Added to CONTRIBUTORS.md
- Mentioned in commit history
- Credited in relevant sections
