## 🏆 Key Projects & Implementations

### 1. 🏥 Patient Management System (Day 02)
- **Directory:** `01_Python_Basics/day02_control_flow_loops.ipynb`
- **Core Technologies:** Python Control Flow, Dictionaries, Nested Lists, While-Loop CLI.
- **Features:**
  - Interactive menu-driven console interface for clinic receptionists.
  - Dynamic patient registration with validation for medical history and contact data.
  - Doctor appointment allocation and scheduling logic.
  - Real-time patient lookup and formatted tabular output.

### 2. 🏛️ Hospital Management System (Day 07)
- **Directory:** `02_Python_OOP/day07_oop_encapsulation_inheritance.ipynb`
- **Core Technologies:** Object-Oriented Programming, Encapsulation, Inheritance, `super()`.
- **Features:**
  - Robust class hierarchy modeling Doctors, In-Patients, Out-Patients, and Medical Staff.
  - Strict encapsulation with private attributes (`__patient_id`, `__billing_amount`) protected by getters and setters with validation rules.
  - Polymorphic billing calculators accounting for ward charges, consultation fees, and emergency surcharges.

### 3. 🎓 Student Grading & Results Analytics Pipeline (Day 23)
- **Directory:** `07_MySQL_Database/mysql_student_grading_system.ipynb`
- **Core Technologies:** MySQL Relational Database, `mysql-connector-python`, Pandas, NumPy.
- **Features:**
  - Live connection to MySQL database table holding multi-subject student records.
  - Ingests tabular data directly into Pandas via automated SQL queries.
  - Vectorized calculation of percentage, grade bands (A+, A, B, C, F), and student ranking.
  - Statistical summary utilizing NumPy for standard deviation, mean performance per subject, and anomaly detection in class scores.

## 🚀 Getting Started

### Prerequisites
- **Python:** 3.10 or higher
- **Package Manager:** `pip` or `conda`
- **Database:** MySQL Server (e.g., MySQL Community Server or XAMPP)
- **Jupyter Notebook / Lab:** For interactive notebook execution

### 1. Clone the Repository
```bash
git clone https://github.com/muhammadabid236159/AI-100-days-.git
cd AI-100-days-
```

### 2. Set Up Virtual Environment

**Using Conda:**
```bash
conda create -n ai100 python=3.11 -y
conda activate ai100
```

**Or using Python venv:**
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables
Copy the example environment template and supply your local credentials and API keys:
```bash
cp .env.example .env
```
Update `.env` with:
- `GOOGLE_API_KEY`: Your Google Gemini API key
- `DATABASE_URL`, `DB_USERNAME`, `DB_PASSWORD`: Your MySQL database credentials

### 5. Launch Jupyter Notebook
```bash
jupyter notebook
```
Navigate to any folder (`01_Python_Basics`, `02_Python_OOP`, `05_NumPy`, etc.) and run the notebooks cell by cell.
